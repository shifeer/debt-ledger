# Debt Ledger — учёт долгов между студентами (DApp)

Итоговый проект по дисциплине «Технологии распределённого реестра».
Децентрализованное приложение на Scaffold-ETH 2 (Hardhat + Next.js + RainbowKit/wagmi), в котором
студенты фиксируют, кто кому сколько должен, а погашение подтверждается в блокчейне.

## Идея и правила

| Правило | Как обеспечено в контракте |
| --- | --- |
| Долг записывает сам должник | `recordDebt` записывает `msg.sender` как должника |
| Погасить долг может только кредитор | модификатор `onlyCreditor` в `confirmRepayment` |
| Сумма > 0, нельзя быть должным себе, адрес не нулевой | `require` в `recordDebt` |
| Комментарий ≤ 64 байт | `require(bytes(note).length <= MAX_NOTE_LENGTH)` |
| Нельзя погасить дважды | `require(!d.repaid)` |

## Смарт-контракт `packages/hardhat/contracts/DebtLedger.sol`

- **write:** `recordDebt(creditor, amount, note)`, `confirmRepayment(id)`
- **view:** `getDebtsCount()`, `getDebt(id)`, `getAllDebts()`, `netBalance(a, b)`, `owed`, `totalDebtOf`, `totalCreditOf`
- **events:** `DebtRecorded`, `DebtRepaid`

## Тесты `packages/hardhat/test/DebtLedger.t.sol`

11 Solidity-тестов (Hardhat 3 запускает их командой `yarn hardhat:test`):
запись долга, эмиссия событий `DebtRecorded`/`DebtRepaid`, ошибочные сценарии `require`
(не кредитор подтверждает погашение, нулевая сумма, долг самому себе, повторное погашение и др.).

## Фронтенд `packages/nextjs`

- `/ledger` — **страница чтения**: сводка по вашему адресу, таблица всех долгов с фильтрами, проверка «кто кому должен», лента событий.
- `/record` — **страница записи**: форма «Я признаю долг» и список долгов перед вами с кнопкой «Возврат получен».
- Статус транзакции показывается под каждой формой: проверка → «Подтвердите в MetaMask» → ожидание блока → успех (с хешем) / ошибка (с текстом `require`).

## Запуск

Нужны Node ≥ 22.13, Yarn, Git, браузер с MetaMask.

```bash
yarn install
yarn chain     # терминал 1 — локальная сеть Hardhat (chainId 31337)
yarn deploy    # терминал 2 — деплой DebtLedger
yarn start     # терминал 3 — фронтенд на http://localhost:3000
yarn hardhat:test   # тесты контракта
```

### Подключение MetaMask к локальной сети

1. MetaMask → «Сети» → «Добавить сеть вручную»: RPC `http://127.0.0.1:8545`, Chain ID `31337`, валюта `ETH`.
2. Импортируйте 2 тестовых аккаунта: в выводе `yarn chain` есть приватные ключи Account #1 и #2 (это публичные тестовые ключи Hardhat, только для локальной сети!).
3. На сайте нажмите **Connect Wallet → MetaMask**.
4. Если после перезапуска `yarn chain` MetaMask пишет об ошибке nonce — Настройки → Дополнительно → «Очистить данные вкладки активности».

## Сценарий ручной проверки

1. Аккаунт A: на `/record` записать долг перед аккаунтом B (например, 150 ед., «обед в столовой») → подписать в MetaMask → «Транзакция выполнена».
2. `/ledger`: долг появился в таблице со статусом «активен», в ленте — событие `DebtRecorded`.
3. Аккаунт A: попробовать записать долг с суммой 0 → ошибка `Amount must be positive`.
4. Аккаунт B: на `/record` нажать «Возврат получен» → статус в реестре «погашен», событие `DebtRepaid`.
